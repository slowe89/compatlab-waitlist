What’s in a Ship pack

  1. Test the clients customers use

    We connect through Cursor, VS Code, Claude Desktop, and Claude Code so you see which clients actually ship — not the Inspector row that stayed green.

  2. Find connection and sign-in failures

    Check resource URLs, cached sign-in state and client registration. See which step fails in each client and what needs to change.

  3. Retest after client updates

    Optional monthly retests check whether client updates have broken a connection that worked before.

Who for

Operators and vendors of remote MCP servers that customers connect to through agent clients.

Who not

Teams without a remote server URL ready to test, or teams working only with local stdio connections.
